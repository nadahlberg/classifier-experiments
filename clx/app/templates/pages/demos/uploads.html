How it works

  • Files are stored in the private bucket, namespaced as user id / upload id / filename.
  • Previews and downloads stream through Django, so ownership is checked on every request and the same code works on local storage and S3.
  • Limits — {{ max_files }} files per upload, {{ max_size_mb }} MB each — are enforced in the modal for feedback and in the service for real.
  • Images and videos preview inline, PDFs render their first page, HTML renders scaled down in a sandboxed iframe, and small text files show their opening lines. Office documents keep a type icon — real thumbnails for those need server-side rendering.
  • Deleting a card removes the row and the stored object.
