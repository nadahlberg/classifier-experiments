Rate limit tiers

    

      A request is counted against every tier that applies to it, and the
      first one to run out is what returns the 429.
    

  


  

    

      
Per session · {{ per_session_limit }}/hr

      

        Browser traffic only, and much looser: a polling page legitimately
        makes thousands of calls an hour.
      

    

    

      
Per user · {{ per_user_limit }}/hr

      

        The aggregate ceiling across a user's tokens, so minting a fresh
        one does not reset it. Sessions cannot rotate, so it skips them.
      

    

    

      
Per user and scope

      

        Separate budgets per scope, so a polling read workload cannot
        exhaust what a write workload depends on.
